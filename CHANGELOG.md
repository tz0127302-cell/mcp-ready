# Changelog

## 0.1.0

- Source repository: https://github.com/tz0127302-cell/mcp-ready. Not published to npm.
- `scan` scores an OpenAPI 3 document or a source tree from 0 to 100.
- `generate` writes a TypeScript stdio MCP server that starts in mock mode.
- `init` adds `llms.txt`, `mcp.manifest.json`, and `AGENTS.md`.
- Reports render as a terminal checklist, JSON, or Markdown.
